# Everplay site

A 4-page Eleventy site (Home / About / Pricing / Login) with a Decap CMS
dashboard at `/admin` for editing the game library, pricing tiers, and
About page content without touching code.

## Project structure

```
src/
  _data/
    games/        one JSON file per game — the CMS "Game Library" collection
    games.js       merges those files into one `games` list for templates
    pricing.json   pricing tiers + FAQ text
    team.json      About page hero copy + team bios
    home.json      homepage heading/subtext
  _includes/
    base.njk       shared header/nav/footer used by every page
  index.njk, about.njk, pricing.njk, login.njk   page templates
  admin/           the Decap CMS dashboard (config.yml + index.html)
  css/tailwind.css  source styles, compiled to css/style.css at build time
```

## Local development

```
npm install
npm start        # builds CSS, builds the site, and serves it with live reload
```

Then open the printed localhost URL. `npm run build` produces a static
`_site/` folder you could also open directly or upload anywhere.

## Going live (Netlify + GitHub)

1. Push this folder to a new GitHub repository.
2. In Netlify, click **Add new site → Import an existing project**, pick
   the repo. Netlify will read `netlify.toml` and auto-fill the build
   command (`npm run build`) and publish directory (`_site`) — just confirm
   and deploy.
3. Your site is live at a `*.netlify.app` URL immediately; add a custom
   domain later under **Domain settings** if you want one.

Every push to the `main` branch after this will auto-rebuild and redeploy.

## Turning on the dashboard (Netlify Identity + Git Gateway)

The `/admin` dashboard needs two things enabled in your Netlify site
dashboard (both free, a few clicks, one-time setup):

1. **Site settings → Identity → Enable Identity.**
2. Under Identity **Registration**, set it to **Invite only** (so random
   people can't sign themselves up).
3. **Site settings → Identity → Services → Git Gateway → Enable Git Gateway.**
   This is what lets the dashboard commit content changes to your GitHub
   repo on your team's behalf, without anyone needing their own GitHub
   account or token.
4. Back on the Identity tab, click **Invite users** and enter your
   teammates' emails. They'll get an email link that drops them straight
   into a "set your password" screen, then into `/admin`.

Once that's done, anyone you invite can go to `yoursite.netlify.app/admin`,
log in, and edit:

- **Game Library** — add, remove, reorder, or edit any game (title, genre,
  price, cover image, hover-preview video, icon, accent color).
- **Pricing Page** — the three pricing tiers and the FAQ text.
- **About Page** — the hero copy, team member cards, and the newsletter CTA.
- **Homepage** — the heading and subtext above the game grid.

Every save creates a commit in your GitHub repo and kicks off a new Netlify
build (takes 30–60 seconds), so the live site updates automatically —
no one needs to touch code or redeploy manually.

## Notes / things worth knowing

- Game cover images and team photos currently point at temporary Google
  AI Studio URLs from the original Stitch export. They work today, but
  aren't guaranteed to stay online long-term — re-uploading them through
  the dashboard's image picker (which stores them in this repo under
  `src/images/uploads`) will make them permanent.
- `src/css/style.css` is generated by the build and isn't committed to git
  — don't hand-edit it, edit `src/css/tailwind.css` instead.
- If you ever want more people to have *developer* access (editing
  templates, not just content), give them GitHub repo access — Identity/Git
  Gateway logins are separate from that and only grant `/admin` access.
